# Awra 1 documentation (historical)

These documents describe Awra 1, the GTK 4.22 framework that Awra 2
replaces. Awra 2 keeps its visual language (tokens, materials, components)
one to one, so `architecture/visual-language.md` and the component specs
remain the reference for how things look; everything about GTK, GObject,
CSS, Meson and GIR no longer applies. See [`../architecture.md`](../architecture.md).
